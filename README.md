# Neurona

This repository is a collection of functions for the analysis of **sequential dynamics** in neural activity. It includes:

- Processing of intracellular and extracellular signals.
- Metrics from synchronization, excitability, variability and intervals in the sequence
- Machine learning tools for the analysis of those metrics and traces.
- Cycle-by-cycle analysis of metrics and intervals.

In addition this repository includes such analyses for the pyloric CPG in the stomatogastric ganglion of *Carcinus maenas*.

The figures folder has **images** from these results:
- Figures of invariants for each experiment. Both in pairplots and 3Dplots of the most relevant ones.
- Figures of the analyses cycle-by-cycle.
- Figures of the relationship between metrics.
